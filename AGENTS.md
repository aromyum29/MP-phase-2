## User iteration scope (12 October 2026)

All future requested changes apply to iteration 1 only unless the user explicitly names another iteration or requests both. Preserve iteration 2 as the comparison baseline. Its sidebar uses the original flat navigation, with no category dropdowns or primary/category spacing. Iteration 1 uses the compact, icon-led expandable categories, closed by default, with at most one category expanded at a time. Keep the version switcher available in both. Shared components must be gated by iteration or separated when changing iteration-1 behavior. Do not undo previously shared feature changes unless requested.
